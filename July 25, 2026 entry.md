## 2. What I Learned

Today I learned about the overall process of **making data useful**, which includes data preparation and data analysis.

I learned that before analyzing data, I need to understand the business or analytics problem and identify what data is actually needed to answer the questions.

I also learned about different **data quality attributes**, including:

* **Consistency** — data should not contradict across sources.
* **Accuracy** — data should correctly represent the actual value.
* **Completeness** — required data should not be missing.
* **Auditability** — changes to data should be traceable.
* **Validity** — data should follow the correct format and rules.
* **Uniqueness** — records should not be unnecessarily duplicated.
* **Timeliness** — data should be updated and available when needed.

## 3. Lesson Summary

### Making Data Useful

The lesson introduced the process of turning raw data into information that can support decisions.

The general process includes defining the problem, identifying relevant data, checking data quality, preparing the data, analyzing it, and interpreting the results.

### Data Preparation

Data preparation is the broader process of making raw data ready for analysis or modeling. It can include cleaning, integrating, formatting, validating, and splitting datasets.

### Data Transformation

Data transformation is a more specific process that changes the format, structure, or values of data to make it suitable for a particular analysis or machine learning algorithm.

### Data Quality

Good analysis depends on good-quality data. Issues such as duplicates, missing values, inconsistent formats, invalid values, incorrect formulas, negative values, and future dates can affect the reliability of analysis.

### Data Analysis

Data analysis involves working with data to discover useful information, identify patterns, test relationships, examine trends, visualize information, and ultimately support decision-making.

---

## 4. Key Takeaways

1. Start with the **problem**, not the data.
2. Identify the data needed to answer specific questions.
3. Data quality must be checked before analysis.
4. Data preparation and data transformation are related but not exactly the same.
5. Analysis should lead to insights that can help solve the original problem.
6. Recommendations should be supported by evidence from the data.
